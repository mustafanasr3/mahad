# Mahad Next.js

النسخة الجديدة قيد الإعداد باستخدام Next.js App Router وTypeScript وTailwind CSS. لم تُنقل وظائف الموقع أو بياناته في هذه المرحلة؛ ملفات Python وقاعدة البيانات الأصلية تبقى دون تغيير.

## المتطلبات والتشغيل

- Node.js 20.9 أو أحدث.
- تثبيت الاعتمادات: `npm ci`
- تشغيل التطوير: `npm run dev`
- فحص الأنواع: `npm run typecheck`
- فحص ESLint: `npm run lint`
- إنشاء تصدير ثابت: `npm run build`

ينشئ أمر البناء الموقع الثابت داخل `out/`.

## GitHub Pages

إعداد `basePath` الافتراضي هو `/mahad` لصفحة GitHub Pages الخاصة بالمشروع، و`trailingSlash` مفعّل لتوليد مجلدات صفحات متوافقة مع الاستضافة الثابتة. استخدم المتغير `NEXT_PUBLIC_BASE_PATH` عند البناء لتغيير المسار؛ مثلًا `/اسم-المستودع` لمستودع آخر أو قيمة فارغة للنشر على نطاق الجذر. يجب أن يكون المسار مطلقًا بلا شرطة مائلة نهائية، وألا تحتوي مقاطعه على مسارات نسبية.

أُوقف تحسين الصور من Next.js لأن التصدير الثابت لا يشغّل محسن الصور على الخادم.

## إعدادات Supabase

انسخ `.env.example` إلى `.env.local` عند الحاجة، ثم أضف عنوان المشروع ومفتاح النشر فقط. `.env.local` مستثنى من Git. لا تضف Supabase Secret Key أو أي أسرار إلى الواجهة الأمامية أو ملفات البيئة العامة؛ لا توجد اتصالات أو عمليات على قاعدة البيانات في هذه المرحلة.
