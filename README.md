# د.مالك بن رضا المحمدي

مكتبة علمية تعرض برامج ودروس وفوائد الشيخ د. مالك المحمدي - وفَّقه الله -. يعمل الخادم ببايثون وSQLite دون مكتبات خارجية.

## التشغيل المحلي

يتطلب Python 3.8 أو أحدث:

```powershell
python server.py
```

ثم افتح `http://localhost:8000`. في أول تشغيل تُنشأ قاعدة البيانات وحساب المشرف بكلمة مرور مؤقتة عشوائية تظهر مرة واحدة في نافذة الطرفية؛ احفظها ولا تشاركها. سيُطلب تغييرها إلى كلمة مرور من ١٢ حرفًا على الأقل عند أول دخول، ولن تُتاح وظائف الموقع للمشرف قبل ذلك. لتحديد اسم الحساب قبل أول تشغيل:

```powershell
$env:ADMIN_USER = "admin"
python server.py
```

إذا كانت قاعدة البيانات موجودة بالفعل وتريد فرض كلمة مرور مؤقتة جديدة على حساب مشرف، أوقف الخادم وشغّل الأمر التالي؛ ستظهر كلمة عشوائية جديدة مرة واحدة، وتُلغى الجلسات الحالية:

```powershell
python server.py resetpass admin
```

لتعيين كلمة مرور يدويًا لاحقًا:

```powershell
python server.py setpass admin كلمة_جديدة
```

## استعادة كلمة المرور عبر تيليجرام

تحتاج الميزة إلى بوت تيليجرام. أنشئه عبر `@BotFather`، ثم أوقف الخادم واضبط رمز البوت كمتغير بيئة قبل تشغيله مجددًا؛ لا تضع الرمز في ملفات المشروع ولا ترسله في المحادثات:

```powershell
$env:TELEGRAM_BOT_TOKEN = "رمز_البوت"
python server.py
```

اسم المستخدم يُكتشف تلقائيًا من تيليجرام. بعد تسجيل الدخول، افتح «حسابي» واختر «إنشاء رابط الربط»، ثم افتح الرابط وابدأ المحادثة مع البوت. يمكن بعدها طلب رمز استعادة من صفحة تسجيل الدخول. الرمز صالح لعشر دقائق، ومحدود المحاولات والطلبات، وكلمة المرور الجديدة يجب ألا تقل عن ١٢ حرفًا. يتطلب إرسال واستقبال الرموز أن يبقى الخادم مشغّلًا مع متغير البوت مضبوطًا.

لتشغيل البوت محليًا: أنشئ البوت من `@BotFather` وخذ الرمز، ثم أوقف خادم الموقع واضبط الرمز في **نافذة PowerShell نفسها** التي ستشغّل الخادم منها:

```powershell
$env:TELEGRAM_BOT_TOKEN = "الرمز_الذي_أعطاك_إياه_BotFather"
python server.py
```

يبقى البوت يعمل ما دام الخادم يعمل. لا ترسل الرمز في المحادثات ولا تحفظه في ملفات المشروع. لا يمكن تشغيل البوت دون رمز BotFather خاص بحسابك؛ متغير `TELEGRAM_BOT_USERNAME` اختياري إذا لم يكتشف الخادم اسم المستخدم تلقائيًا.

## المكتبة

تعرض الرئيسية المكتبة أولًا، ثم **الكلمات** و**الفوائد** و**الخطب المنبرية** و**الكتب** والأسئلة الشائعة. تظهر شرائح الكلمات والفوائد عنصرًا واحدًا في كل مرة، وبحد أقصى ١٥ عنصرًا لكل قسم. من لوحة التحكم ← **الفوائد** يمكن إضافة YouTube Short برابطه لعرضه وتشغيله داخل الموقع، أو رفع مقطع محلي. ومن لوحة التحكم ← **الكلمات** يمكن إضافة رابط منشور يوتيوب مع عنوانه ونصه ورابط صورته؛ يبقى المنشور معروضًا داخل الموقع، وتعمل الروابط المكتوبة ضمن نصه كرابط خارجي. يمكن للمشرفين نشر إعلان مصوّر أو نصي من لوحة التحكم ← **الإعلانات**؛ يظهر الإعلان في نافذة عند زيارة الموقع ويُضاف تلقائيًا إلى **الكلمات**. حدّد قيمة «الترتيب» لمطابقة ترتيب القناة عند إدخال العناصر. تعرض المكتبة البرامج والتعليقات والشروح المرتبطة بالمعهد، والمحتوى بنوعه: قائمة تشغيل أو فيديو أو مجلس صوتي. تفتح القوائم والفيديوهات في صفحة مشاهدة تعرض مشغل يوتيوب وقائمة الفيديوهات، مع روابط للقوائم الأخرى في العلم نفسه وقسم لمجالس علوم مرتبطة. يستطيع المستخدم المسجل طرح سؤال عن الدرس، ولا يمكن نشر الإجابات إلا لحسابات المشرفين. تظهر إشعارات الرسائل والأسئلة وإجابات المشرفين في لوحة جانبية، مع تنبيه صوتي ونافذة منبثقة للرسائل الجديدة. تتضمن القوائم صفحات **الكتب** و**الخطب المنبرية** ببحث مستقل.

تُرتّب مكتبة العلوم حسب العلم من دون فواصل بعناوين بين مجموعات القوائم، مع إمكانية البحث والتصفية، وتعرض الرئيسية ثماني قوائم. ويمكن البحث في محتوى المكتبة من لوحة التحكم. أُضيفت المقاطع والمنشورات المتاحة من القناة عند الاستيراد إلى قسمي **الفوائد** و**الكلمات** مع ترتيبها؛ يظل المنشور نفسه داخل الموقع، بينما تفتح الروابط الظاهرة في نصه كرابط خارجي. إضافات القناة اللاحقة تُضاف من لوحة التحكم يدويًا.

تعرض روابط X ويوتيوب وتليجرام وواتساب كأيقونات في التذييل، ويظهر اسم الرابط عند تمرير المؤشر عليه. يمكن تحديث الروابط من لوحة المشرف ← الإعدادات. يمكن للطلاب والمشرفين مراسلة بعضهم عبر الشريط الجانبي الداخلي، ولا يُسمح بمراسلة طالب لطالب. شعار الموقع هو الصورة الموجودة في `static/img/malik-logo.jpg`.

صورة الاسم الخطية المرفقة في التذييل، مع عبارة «فضيلة الشيخ الدكتور» داخل الصورة، محفوظة بصيغة PNG شفافة في `static/img/footer-calligraphy-from-user.png`.

## متابعة التعلم والمحتوى

- يُسجّل تقدم الطالب وموضع توقفه كل ١٠ ثوانٍ وعند إيقاف الفيديو، ويُعلّم الدرس مكتملًا عند انتهائه. تعرض لوحة المشرف أسماء الطلاب وموضعهم وحالة الإكمال. تتطلب المتابعة تشغيل فيديو يوتيوب واتصالًا يسمح بتحميل YouTube IFrame API.
- من لوحة المشرف يمكن إضافة كتاب برابط HTTPS أو ملف PDF، وإضافة خطبة منبرية كرابط أو كملف فيديو أو صوت. اختر الرابط أو الملف فقط؛ الحد الأقصى للملف ٢٥ ميجابايت.
- من لوحة المشرف ← **الفوائد** تُضاف مقاطع Shorts برابط YouTube لتشغيلها داخل الموقع، كما يمكن رفع فيديوهات محلية على أجزاء ٨ ميجابايت وبحد أقصى ٨ جيجابايت؛ فيديو 720p مدته ٣–٤ ساعات يحتاج مساحة تخزين واتصالًا مستقرًا وقد يتجاوز الحد بحسب معدل الضغط. الصيغ المدعومة MP4/M4V/MOV/WEBM/MKV/AVI، ويتطلب تشغيل الملف دعم صيغة الفيديو في المتصفح.
- من لوحة المشرف ← **الكلمات** يمكن حفظ رابط منشور يوتيوب مع عنوانه ونصه ورابط صورته. الرابط مصدر إداري فقط ولا يُعرض للزوار؛ أدخل النص والصورة يدويًا، واضبط الترتيب كما تريد.
- من لوحة المشرف ← **مكتبة المحتوى** اختر قائمة تشغيل أو فيديو أو مجلسًا صوتيًا. الفيديو والصوت يقبلان رابطًا أو ملفًا مرفوعًا حتى ٢٥ ميجابايت. ويمكن إرفاق ملفات اختيارية بقائمة التشغيل (PDF أو صوت حتى ٢٥ ميجابايت).
- يدعم خادم الملفات طلبات HTTP Range لتشغيل الفيديو والانتقال إلى مواضع مختلفة؛ ويُخزّن الملف كاملًا على القرص في `static/uploads`، لذا تأكد من توفر المساحة الكافية وخذ نسخًا احتياطية منها.
- غرف البث تُدار من لوحة المشرف ← **غرف البث المباشر**. أنشئ حدثًا في StreamYard On-Air ثم أضف رابط المشاهدة `streamyard.com`، وحدد الموعد والجمهور والحالة. تُفتح صفحة الحدث في المتصفح، ولا يحتاج الطلاب إلى تنزيل تطبيق. يتطلب إنشاء البث حسابًا منفصلًا لدى StreamYard؛ الموقع لا ينشئ الحدث أو الحساب نيابةً عنك.
- تتضمن سياسة الخصوصية إشعارًا بأن تقدم الطالب يظهر للمشرفين لأغراض المتابعة.

## قاعدة بيانات موجودة مسبقًا

**خذ نسخة احتياطية قبل أول تشغيل على قاعدة قديمة.** ترحيلة المكتبة الأصلية (`malik_library_v1`) تستبدل إعدادات الموقع والأسئلة الشائعة، وتحذف البرامج القديمة ومحاورها وخططها وتسجيلات الطلاب والصادر والقوائم المحفوظة والفيديوهات القديمة، ثم تهيّئ قوائم القناة الجديدة. تبقى حسابات المستخدمين وسجلات الرسائل القديمة في قاعدة البيانات، ولا يعرضها الموقع. أما ترحيلات أنواع المحتوى والملفات المرتبطة فتضيف الحقول والجداول اللازمة وتحافظ على محتوى المكتبة الحالي. لا تشغّل قاعدة قديمة على نسخة الموقع قبل مراجعة النسخة الاحتياطية ومصير بياناتك.

يُحدد مسار قاعدة البيانات بالمتغير `DB_PATH`؛ وإلا تُستخدم `mahad.db` بجوار `server.py`.

## إدارة الموقع

بعد تسجيل الدخول، تتيح لوحة المشرف إدارة الطلاب والمشرفين ومحتوى المكتبة والعلوم والكلمات والكتب والخطب المنبرية والفوائد ومتابعة التقدم وغرف البث والأسئلة الشائعة وإعدادات الموقع. يمكن للزوار تصفح المحتوى؛ ويستطيع صاحب الحساب حفظ قوائم التشغيل في ملفه الشخصي.

في تبويب «مكتبة المحتوى» بلوحة المشرف، حدّد مربعات العناصر المراد حذفها ثم اضغط «حذف المحدد» لإزالتها دفعة واحدة. تُعرض صورة القائمة المخصصة كما هي، وتُستخدم صورة الفيديو من يوتيوب عند توفرها؛ أما المحتوى بلا صورة فيظهر بشعار المعهد.

يمكن لكل مستخدم تغيير صورته الشخصية أو إزالتها من «حسابي». تُقبل صور JPG وPNG وWEBP حتى ٣ ميجابايت.

## معاينة الموقع

- على الجهاز نفسه: افتح `http://localhost:8000`.
- على شبكة محلية: شارك عنوان الجهاز المحلي والمنفذ `8000` بعد السماح به في جدار الحماية.
- للمعاينة عبر الإنترنت: انشر الموقع خلف HTTPS قبل إرسال الرابط. لا تشارك رابط `localhost` أو بيانات دخول المشرف.

للنشر خلف HTTPS فعّل `SECURE_COOKIE=1`، وفعّل `TRUST_PROXY=1` فقط عند استخدام وكيل موثوق. احتفظ بنسخة احتياطية من قاعدة البيانات ومجلد `static/uploads`.

## البنية

- `server.py` — خادم الموقع وواجهات API.
- `seed.py` — الإعدادات والتصنيفات وقوائم التشغيل الأولية.
- `static/` — واجهة الموقع وملفاتها.

المتغيرات المدعومة: `HOST` (افتراضي `0.0.0.0`)، `PORT` (افتراضي `8000`)، `DB_PATH`، و`SECURE_COOKIE` و`TRUST_PROXY`.

## النشر الحي على Render وSupabase

يستخدم الموقع خادم Python لواجهات API وتسجيل الدخول ولوحة المشرف؛ لذلك لا يستطيع GitHub Pages تشغيل التطبيق الكامل. ملف `render.yaml` يجهّز خدمة الويب على Render في فرانكفورت، بينما يبقى GitHub مستودع المصدر. SQLite يظل قاعدة التشغيل المحلي، ويُستخدم PostgreSQL عند ضبط `DATABASE_URL`.

1. أنشئ مشروع Supabase باسم «مالك المحمدي» في منطقة أوروبية، مثل فرانكفورت، واحتفظ بكلمة مرور قاعدة البيانات في مدير كلمات مرور.
2. اربط مستودع GitHub بحساب Render، ثم أنشئ خدمة Blueprint من `render.yaml`. أدخل رابط PostgreSQL من Supabase في المتغير السري `DATABASE_URL`؛ استخدم رابط Session Pooler مع SSL، ولا تحفظ الرابط في ملفات المشروع أو GitHub.
3. بعد تشغيل الخدمة، انسخ بيانات دخول المشرف المؤقتة من سجل بدء التشغيل على Render وغيّر كلمة المرور عند أول دخول.
4. لنقل المحتوى العام من `mahad.db` المحلية، ثبّت المتطلبات محليًا وشغّل `python scripts/migrate_content.py --apply`. سيطلب السكربت رابط Supabase دون إظهاره، ثم ينقل العناصر المنشورة والإعدادات العامة فقط؛ لا ينقل حسابات أو جلسات أو رسائل أو بيانات مستخدمين. لتجربة أعداد العناصر دون كتابة، شغّله بلا `--apply`.

تُضمّن ملفات الصور التسعة المستخدمة في الكلمات المنشورة الحالية. خطة Render المجانية لا توفر تخزينًا دائمًا للملفات التي يرفعها المشرف بعد النشر؛ يلزم إعداد تخزين دائم قبل الاعتماد على رفع ملفات جديدة. لا تضع كلمات المرور أو روابط الاتصال أو رموز البوت في ملفات المستودع.
